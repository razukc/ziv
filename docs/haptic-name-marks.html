Ziv · haptic name marks

Feel the full interaction language: each candidate name spelled in vibro-braille, the attention vocabulary that rides on it, any word spelled on demand, and self-test modes (M1 session, blind A/B). One beat per braille cell: long buzz = heavy cell (more dots), short buzz = light cell (fewer dots); attention patterns play as ticks (▪), a ramp (▴), a heartbeat (♥), a falling close (▾) and one long buzz (▬).

Attention vocabulary — the words around the name

Short non-letter patterns (plan §4). The name mark says who is talking; these say why the device buzzed. The prefix card plays the mark first, then the reason.

Session mode — protocol M1: name, or not name?

8 randomized rounds: 4 × the Ziv mark, 4 × distractors drawn without replacement from the Boaz / Razu / Buz arcs and the attention patterns. Answer Name or Not name right after each pattern — reaction time runs from the end of the pattern to your tap (replays are counted and logged, never hidden; a round left unanswered 10 s after the pattern ends is scored not-name and flagged late in the CSV). No feedback mid-session; the ≥ 80% working gate is scored at the end and everything downloads as CSV for the logging sheet. For self-administered checks — the facilitated session runs per docs/NAMING_VALIDATION_PROTOCOL.md §3.

Blind A/B — which arc do you actually recognize?

A random candidate mark plays; guess which one it was before the reveal. The per-arc tallies and guess log below measure recognition, not preference. The checkbox adds the retired Raz reference — its twin arc differs from Ziv only in the middle beat (a = 1 dot vs i = 2 dots), so it is the honest hard mode.

Spell any word — the whole alphabet, felt

Type a word and feel it spelled in vibro-braille, one cell per letter (buzz = 50 + 60 × dots, gap = the slider). The 26-letter table is generated from the timing spec, so this box spells exactly what the band can spell — including the week-6 rename candidates: the quick fills below spell the same heavy-light-heavy arc as Z-I-V (protocol §5 option B — arc-validated only; legal screening per plan §1 before adoption).

Feel it on your Android phone

  1. Serve this folder from your computer: python -m http.server 8000
  2. On the phone (same Wi-Fi), open http://COMPUTER-IP:8000/docs/haptic-name-marks.html in Chrome
  3. Tap Play on a card. No vibration? Chrome menu → Site settings → Vibration → Allow. iOS Safari has no Vibration API — you get the visual rhythm only.
